# DevConf 2026 - Tech Conference Website (Day 3)

This project applies foundational CSS styling to the Day 2 semantic HTML structure. It focuses on professional typography, consistent color schemes, and clean layouts using the CSS box model.

## Styling Overview
- **Typography**: 
  - Headings: `Inter` (Bold, Modern)
  - Body: `Roboto` (Clean, Readable)
- **Color Palette**:
  - Primary: Deep Blue (`#0F172A`)
  - Secondary: Sky Blue (`#38BDF8`)
  - Accent: Pink (`#F472B6`)
  - Text: Slate (`#334155`)
  - Background: Off-white (`#F1F5F9`)
- **Layout**: Uses CSS Flexbox for navigation and a centered `main` container for content.

## Project Structure
- `index.html`: Main landing page (Root).
- `pages/`: Sub-pages (About, Speakers, etc.).
- `css/`: Contains `styles.css`.
- `assets/`: Images and videos.

## Key Features
- **Global Reset**: Ensures consistent rendering across browsers.
- **Responsive Navigation**: Flexbox-based menu with hover effects.
- **Styled Forms**: Custom input fields, buttons, and fieldsets.
- **Visual Hierarchy**: Clear distinction between headings, paragraphs, and lists.
