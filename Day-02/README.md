# DevConf 2026 - Tech Conference Website (Day 2)

This project enhances the foundational Day 1 website with advanced HTML5 features, including semantic structure, complex forms, and multimedia integration.

## Enhancements Checklist
- [x] **Semantic HTML**: Replaced generic `div`s with `header`, `nav`, `main`, `section`, `article`, `footer`.
- [x] **Registration Form**: Complex form with validation, fieldsets, and various input types.
- [x] **Multimedia**: Integrated video introductions and promotional videos.
- [x] **Contact & FAQ**: New pages with specific semantic requirements (`address`, `dl`).
- [x] **File Organization**: Structured into `pages/` and `assets/`.

## Project Structure
- `index.html`: Main landing page (Root).
- `pages/`: Contains all sub-pages (About, Speakers, Schedule, Sponsors, Register, Contact, FAQ).
- `assets/`: Contains `images/` and `videos/`.

## Interactive Features
- **Video Player**: Native HTML5 video with controls and posters.
- **Form Validation**: Client-side validation for required fields, email patterns, and dates.
