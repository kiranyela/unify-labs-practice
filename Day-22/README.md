# PROJECT NEXUS: Real-time Data & Analytics Hub

A modular, high-performance web app that aggregates real-time data from CoinGecko. Features include search, sort, favorites, dark/light mode, and persistent state.

## Features

- Modular ES6 architecture (API.js, UI.js, App.js)
- Real-time data fetching with error handling
- Dynamic DOM rendering and search/sort
- Favorites/watchlist with localStorage persistence
- Dark/Light mode toggle

## How to Run

1. Open `index.html` in a modern browser (with local server for ES6 modules)
2. Explore, search, sort, and favorite coins
3. Toggle dark/light mode
