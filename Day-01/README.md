# DevConf 2026 - Tech Conference Website (Day 1)

This project is the foundational HTML structure for the DevConf 2026 website. It demonstrates core HTML5 skills including logical document structure, navigation, text formatting, lists, tables, and image integration.

## Project Structure
- `index.html`: Homepage with conference overview and stats.
- `about.html`: Detailed information about the conference mission and target audience.
- `speakers.html`: Profiles of keynote speakers.
- `schedule.html`: Two-day event schedule using tables.
- `sponsors.html`: Information on sponsor tiers and benefits.
- `images/`: Directory for project assets.

## Learning Objectives
- HTML5 Document Structure
- Navigation and Linking
- Content Organization (Headings, Paragraphs)
- Lists (Ordered & Unordered)
- Data Representation (Tables)
- Media Integration (Images)
